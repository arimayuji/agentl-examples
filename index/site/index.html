Run any example yourself.

Python 3.10 or newer. Every source is public and needs no key; the spending example uses an optional OpenRouter key for its summaries. Each folder has a pipeline.yaml, a run.py and the static site.

$ pip install agentl-etl

Clone and run one

$ git clone https://github.com/arimayuji/agentl-examples $ cd agentl-examples/quakes # or: fx, spending $ python run.py && python -m http.server -d site 8000
